Unity 控制器 0.5.0 · 允许的操作

连接环境外指定的 Unity 项目。可按项目哈希连接，查询场景层级、对象标识、相机、碰撞、构建与渲染状态，搜索指定类型的项目资源。可创建、载入、保存、修复场景，增删对象和指定内置组件，编辑预制体、材质、纹理、网格、动画、特效、天空盒、渲染与 UI，复制、移动、改名或删除指定数据文件。支持创建动画控制器与剪辑、编辑 Transform 曲线，配置物理材质和物理设置，管理指定相机扩展、画质、光照探针、Volume 配置及 UI 面板。可撤销、重做、清空日志，截图保存于 Assets/Screenshots，每批最多 20 项。结果仅含选定的项目数值、对象 ID 和状态。禁止读取文档、原始日志、网络配置或外部应用信息，禁止 Blender、外部服务和任意代码执行。逐项清单见「允许的操作」。

读取与编辑边界

指定项目可用对象 ID 定位。仅返回筛选后的 ID、计数、变换、数值和布尔状态。任意文本（包括对象名和路径）、图像、二进制附件、窗口和程序集清单、包源、端点及原始错误不会经控制器返回。截图仅写入项目。上游查询可能仅返回成功状态。Unity 自身加载的编辑器扩展和资源导入回调沿用该进程已有的系统权限。

调用入口

  • unity_controller_batch Execute up to 20 project operations sequentially. All requests are validated before connecting; any disallowed operation rejects the entire batch.
  • unity_controller_instances List the hashes of connected Unity projects without selecting a project.
  • unity_controller_status Read the connection status and the configured Unity Editor instance.
  • unity_controller_catalog List permitted Unity operations and their argument schemas. Only explicitly permitted project actions are available.
  • unity_controller_read Read editor, project, camera or object/component information from the configured Unity instance.
  • unity_controller_call Invoke a permitted Unity operation on the configured instance. May change or delete project data.

资源和参数限制

可读资源为 mcpforunity://editor/selection, mcpforunity://rendering/stats, mcpforunity://scene/cameras, mcpforunity://scene/gameobject/{id}, mcpforunity://scene/volumes。

场景诊断可显式请求修复。批次全部通过检查后顺序执行，已经完成的编辑不会回滚。通用资源操作支持 .anim, .controller, .jpeg, .jpg, .mat, .mesh, .mp3, .ogg, .physicmaterial, .physicsmaterial2d, .png, .prefab, .spriteatlas, .tga, .unity, .wav。搜索范围固定为 Assets，限指定项目资源类型。纹理输出限 PNG，截图输出目录固定为 Assets/Screenshots。动画曲线仅能绑定 Transform 的位置、旋转和缩放。相机 Body、Aim 和扩展只接受清单中的内置类型。UI 面板编辑限布局和显示属性。

相机支持 CinemachineFollow、CinemachineThirdPersonFollow、CinemachinePositionComposer、CinemachineRotationComposer、CinemachineHardLookAt、CinemachineConfiner2D、CinemachineConfiner3D 和 CinemachineDeoccluder。通用组件编辑仅接受单个指定属性，以及数值、布尔值或数值向量。

  • Rigidbody · angularDrag, drag, isKinematic, mass, useGravity
  • BoxCollider · center, enabled, isTrigger, size
  • SphereCollider · center, enabled, isTrigger, radius
  • CapsuleCollider · center, direction, enabled, height, isTrigger, radius
  • Camera · depth, enabled, fieldOfView, orthographic, orthographicSize
  • Light · enabled, intensity, range, spotAngle
  • MeshRenderer · enabled
  • SpriteRenderer · enabled, flipX, flipY, sortingOrder
  • AudioSource · enabled, loop, mute, pitch, volume
